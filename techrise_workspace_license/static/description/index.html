Techrise Workspace License

Ed25519-signed workspace licensing for the TechRise HR mobile app

Issues and verifies per-workspace licences for client Odoo databases. A workspace is identified by its db_uuid, self-registers on first contact with a 30-day trial, and receives an Ed25519-signed status envelope (trial, active, expired, blocked) from /techrise/workspace/check.

Signatures reuse the signing key configured for Techrise Device License, so a client only ever pins one public key. Administrators activate, block or reset a workspace to trial from the Workspaces backend form.
